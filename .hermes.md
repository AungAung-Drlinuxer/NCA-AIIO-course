# Project Context

This repository is an exam-prep course (NVIDIA NCA-AIIO) written in
Burmese for engineers.

Before writing or editing any chapter, follow `WRITING_RULES.md` in this
repository. Key points:

- Natural Burmese; keep established technical terms in English.
- Chapter progression: problem → core concept → technique comparison →
  practical configuration → operational cautions → self-check.
- Exam-oriented generic examples only — never reference the learner's
  own machines, clusters, or projects.
- Preserve diagrams, official NVIDIA image embeds, and references.
- Commands: explain what each does; flag model/driver/version-dependent
  behavior. Never invent specs, commands, or benchmark numbers.
- Every chapter ends with a short "Technical review notes" section.
