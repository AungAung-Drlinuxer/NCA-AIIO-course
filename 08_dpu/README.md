# Module 08 — DPU (Domain 2.10)

## Blueprint objective
- 2.10 Explain the purpose and benefits of a DPU in a datacenter

## အဓိက အကြောင်းအရာ
1. **DPU = Data Processing Unit** (NVIDIA **BlueField**) — CPU ကနေ infrastructure workload ကို လွှဲယူ
2. **ဘာတွေ လွှဲလဲ** — networking (RDMA), storage virtualization, security (encryption), multi-tenancy isolation
3. **အကျိုးကျေးဇူး** — CPU core တွေ လွတ်လာ (AI အတွက် ပြန်ပေး), performance, isolation, zero-trust
4. **BlueField-2/-3/-4** အကျဉ်း + **DOCA** software platform
5. **GPU-DPU ဆက်စပ်မှု** — GPUDirect, SuperPOD မှာ ဘယ်လို ပါ
