# Module 00 — Exam Overview & Study Setup

## Exam အချက်အလက်များ
| အချက် | တန်ဖိုး |
|---|---|
| အမည် | NVIDIA-Certified Associate: AI Infrastructure and Operations |
| Code | NCA-AIIO |
| မေးခွန်း / အချိန် | 50 questions / 60 minutes (~72s per question) |
| Format | Multiple choice (single + multiple response) |
| Delivery | Online, remote-proctored (Certiverse) |
| ကုန်ကျစရိတ် | $125 (course bundle $150) |
| Pass mark | မထုတ်ပြန် (aim 70%+) |
| သက်တမ်း | 2 နှစ် (retake) |
| Prerequisite | data center infrastructure အခြေခံ |

## Domain များ (Official Blueprint)
| Domain | Weight | အကြောင်းအရာ |
|---|---|---|
| 1. Essential AI Knowledge | **38%** | AI/ML/DL, GPU vs CPU, training vs inference, NVIDIA software stack, use cases |
| 2. AI Infrastructure | **40%** | hardware, scaling, power/cooling, facility, networking, DPU, on-prem vs cloud |
| 3. AI Operations | **22%** | DC management/monitoring, orchestration/scheduling, GPU monitoring, virtualization |

## Study resources (official)
- **NVIDIA AI Infrastructure and Operations Fundamentals** (free ~7h self-paced) — blueprint နဲ့ တိုက်ရိုက် ကိုက်
- **NVIDIA Exam Study Guide PDF** (official) — topic list + suggested readings
- Suggested reading: DCGM, Base Command, BMC, Kubernetes docs, Slurm, Docker, MIG, Run:ai "6 Reasons for Low GPU Utilization"

- Kubernetes/kubectl, GPU (RTX 5070 Ti), LLM serving (SGLang/llama.cpp) လက်တွေ့ ရှိပြီးသား
- အားနည်းချက် ဖြည့်ရမည် — data center power/cooling/facility, InfiniBand/DC networking, DPU, MIG/vGPU
