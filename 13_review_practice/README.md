# Module 13 — Review & Practice Exam

## လုပ်ရမည့် အလုပ်များ
1. Domain ၃ ခုလုံး flashcard ပြန်ဖြည့်
2. Practice exam — 50 questions / 60 min timing ဖြင့်
3. **Weak-spot list** ပြုလုပ် (score နိမ့် domain ပြန်ဖတ်)
4. Exam-day checklist: Certiverse setup, webcam, ID, quiet room
5. အမှားများ ပြန်စစ် — ဘာကြောင့် မှားခဲ့သလဲ

## Exam-day strategy
- ~72s/question; ပြန်စဉ်းစားဖို့ ခက်ရင် flag လုပ်ပြီး ရှေ့ဆက်
- Multiple response: အားလုံး ကိုက်ညီမှု စစ်
