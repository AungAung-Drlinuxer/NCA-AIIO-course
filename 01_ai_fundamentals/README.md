## အဓိက အကြောင်းအရာများ
1. **AI > ML > DL** — AI အကျယ်ဆုံး; ML = data ကနေ pattern လေ့လာ; DL = neural network အလွှာများ (GPU လိုအပ်ရခြင်း ဒီက စ)
2. **AI ဘာကြောင့် အခုမှ ပေါက်ကွဲရလဲ** — data အများကြီး + compute (GPU) + algorithm (Transformer) + ရင်းနှီးမြှုပ်နှံမှု
3. **Use cases** — healthcare (imaging), finance (fraud), manufacturing (inspection), chatbot/LLM, recommendation, autonomous vehicles
4. **Training vs Inference ဘာကွာလဲ** (preview — Module 04 မှာ အပြည့်)
5. **Generative AI / LLM / RAG** အကျဉ်း
